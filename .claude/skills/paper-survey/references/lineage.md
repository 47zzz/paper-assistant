# lineage.md — where each mechanic comes from

The skill is a remix of published paper-search / survey-generation systems (research notes 2026-10-08).
Each row says what we borrowed, from whom, and the source URL. Numbers are the published ones.

| stage / mechanic in this skill | borrowed from | what they do (published) | source |
|---|---|---|---|
| Stage 1: query → structured object (intent, sub-criteria, modifiers "recent/classic/central") | **Asta Paper Finder** (Ai2) query analyzer | LLM extracts predefined properties; modifiers shift ranking toward metadata; "a pipeline of manually coded steps with LLM decisions at key points" beat LLM-driven control flow | https://arxiv.org/pdf/2510.21652 (App. F.3); https://allenai.org/blog/paper-finder |
| Stage 1: 2–5 reformulations "some broad, some narrow, some short, some longer, no boolean" | **Undermind** whitepaper prompt | GPT-4 generates 5 keyword searches per request | https://www.undermind.ai/whitepaper.pdf |

Things we deliberately did **not** copy: embedding-based clustering (UMAP+GMM/HDBSCAN) — no
dependencies allowed, and OpenAlex topics + survey headings give a comparable taxonomy for free;
Undermind's exponential fit — replaced by the simpler judged-count cap; full-text reading of every
candidate — abstracts + S2 tldr are enough for tiering at this list size (LitSearch: full text does not
consistently help rerankers).
